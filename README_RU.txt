MULTO AI — веб-прототип для Android

В архиве — PWA-заготовка: мобильный интерфейс, форма идеи, выбор длительности и голоса, демонстрационная карточка проекта.

ВАЖНО: это НЕ полноценный генератор видео. Кнопка формирует демонстрационный план. Для настоящего видео потребуются сервер и подключение ИИ для сценария, изображений/анимации, речи и сборки MP4.

Как открыть на Android без компьютера:
1. Архив нужно сначала разместить на HTTPS-хостинге. Установка PWA через «Добавить на главный экран» требует сайта, открытого по HTTPS (или localhost).
2. Можно использовать сервис хостинга, которым удобно управлять с телефона, например GitHub Pages. Создай репозиторий, загрузи содержимое этой папки в корень и включи Pages в настройках репозитория.
3. Открой полученную HTTPS-ссылку в Chrome на Android.
4. Меню Chrome (⋮) → «Установить приложение» или «Добавить на главный экран».

Если загружаешь файлы на хостинг с телефона, загружай именно содержимое папки, а не ZIP как один файл.
